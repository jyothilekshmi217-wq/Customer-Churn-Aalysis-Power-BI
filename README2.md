Customer Churn Analysis using Power BI
Overview
This project analyzes customer churn patterns using Power BI to identify factors affecting customer retention and revenue.

Key Findings

Customer churn varies by subscription type and contract length.
Usage frequency influences customer retention.
Support interactions are related to churn behavior.
Customer tenure impacts churn patterns.
